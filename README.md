# blabbaphone

Needs to run using some type of web server (you can run a local web server on the command line), like:

On the command line, navigate to the directory where index.html is.

Run "python -m http.server" (will only work if python is installed and has access to that module - another one to try could be "python -m SimpleHTTPServer")

Then open the address that python specifies in a web browser (something like "http://0.0.0.0:8000 or something)
